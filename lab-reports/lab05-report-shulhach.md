## Опис API
Реалізовано REST API на Flask з використанням бази даних SQLite. Додано версіонування (`/api/v1/`), валідацію вхідних даних, обробку помилок у форматі JSON та документацію Swagger (Flasgger).

## Таблиця ендпоінтів
| Метод | Адреса | Призначення | Коди відповідей |
|-------|--------|-------------|-----------------|
| GET | `/api/v1/products` | Отримати всі товари | 200 |
| GET | `/api/v1/products/<id>` | Отримати один товар | 200, 404 |
| POST | `/api/v1/products` | Створити новий товар | 201, 400 |
| PUT | `/api/v1/products/<id>` | Оновити товар | 200, 400, 404 |
| DELETE | `/api/v1/products/<id>` | Видалити товар | 204, 404 |
| GET | `/api/v1/clients` | Отримати всіх клієнтів | 200 |
| GET | `/api/v1/orders` | Отримати всі замовлення | 200 |

## Валідація та версіонування (Рівень 3)
- **Версіонування:** Всі ендпоінти починаються з `/api/v1/`.
- **Валідація:** При створенні/оновленні товару перевіряється наявність полів `title` (рядок) та `price` (число). Якщо дані некоректні — повертається код 400.
- **Обробка помилок:** Налаштовані глобальні обробники для кодів 400, 404 та 500, які повертають JSON замість HTML.
