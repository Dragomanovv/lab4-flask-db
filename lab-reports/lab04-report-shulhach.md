# Звіт до лабораторної роботи №4

**ПІБ:** Шульгач Богдан
**Група:** ІПЗ-21
**Тема проєкту:** Веб-додаток магазину електроніки з адмін-панеллю
**Склад команди:** (1)

## 1. Особистий внесок
Розробив структуру бази даних SQLite (таблиці `feedback`, `clients`, `products`, `orders`), налаштував зв'язки між ними. Реалізував серверну логіку на Flask (CRUD-операції для всіх таблиць). Написав інтерфейс користувача (HTML/CSS) з навігацією та формами.

## 2. Схема бази даних
*   `feedback`: id, name, message (відгуки користувачів).
*   `clients`: id, full_name, email, phone (база клієнтів - Рівень 2).
*   `products`: id, title, price (товари магазину).
*   `orders`: id, client_id, status (замовлення, пов'язані з клієнтами.

## 4. Труднощі та їх вирішення
Під час розробки виникла помилка `ValueError` через використання символу `%` у CSS-стилях при рендерингу шаблону. Її було вирішено заміною оператора форматування на метод `.replace()`.

## 5. Висновок
Під час виконання лабораторної роботи я набув практичних навичок роботи з Flask та SQLite, навчився проєктувати реляційні бази даних, реалізовувати зв'язки між таблицями та створювати адмін-панель. Виконано Рівень 1 та Рівень 2.
